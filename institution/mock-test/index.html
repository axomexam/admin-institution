Before you hand this to a class

How the papers behave, and what students get at the end.

How a paper runs

A set is a full paper, not a quiz: 150 questions in 180 minutes for Grade III and 135 questions in 150 minutes for Grade IV. The timer starts when the student presses Start and keeps running if they switch tabs, so the paper cannot be paused. The question palette on the side shows answered, marked and unvisited questions, and any question can be revisited until the paper is submitted.

Marking and negative marking

One mark per correct answer, −0.25 for each wrong answer, and nothing for a question left blank. The scorecard breaks the total down by subject, so a teacher can see which section pulled a student down rather than only the final number.

What the scorecard contains
  • The candidate's name, date of birth and roll number as entered before the paper.
  • Final score, percentage, accuracy on attempted questions and time taken.
  • A per-subject table: attempted, correct, wrong, skipped, marks.
  • Review of all answers, with the correct option and an explanation for each question.

The scorecard prints as a clean A4 PDF with the axomexam.in watermark, so a batch's results can be filed or handed back on paper.

Two languages, one paper

Each question is stored in both English and Assamese. Students choose their language before starting and can switch mid-paper without losing answers, so a mixed-language batch can sit the same set together.

Running a whole classroom

Everything runs in the browser — there is no server and no per-seat limit, so thirty students can open the same set at the same time. Results stay on each student's own device; nothing is uploaded anywhere. These pages are excluded from search engines and are meant for your students only.

Topic-wise PDFs for revision

Mock tests show where a student stands. For the revision that follows, the institution library has every question bank split into topic-wise PDFs — one file per topic, in English or Assamese, with answers and explanations, so a teacher can hand out exactly the topic that needs work.
